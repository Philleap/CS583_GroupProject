**Omission**

CS583 Group Project

Genre: Third-Person Survival Horror

-------------------------------

Lip Nguyen: Level Design, Mapping, Audio

Keith Macario: Enemy AI

Austin Friesen: Menu, UI, UX, Scene Transitions

Tanuj Thummala: Project Lead, General Programming

Tri Pham: QA, Gameplay Programming

----------------------------------------

Omission is a third-person survival game in which a player goes through alien outbreaks in a lab  facility via puzzle-solving, resource management, and combat. The objective of the player is to shut down a lab portal to end the alien outbreak.
